# JAC Motors Tunisie

Site web dynamique (React + Vite) pour JAC Motors en Tunisie : présentation des pickups **T8** et **T8 PRO**, showrooms, avis Google, et **réservation d’entretien sans login**.

Inspiré du site officiel [jacen.jac.com.cn](https://jacen.jac.com.cn/).

## Pages (5)

1. Accueil
2. Modèles (T8 / T8 PRO)
3. Réserver un entretien
4. Showrooms & contacts
5. Avis Google

## Lancer

```bash
npm install
npm run dev
```

## Réservation

Formulaire : matricule, nom, email, téléphone, modèle, showroom, date/heure disponibles.  
Ticket généré localement (localStorage) avec téléchargement / impression.
